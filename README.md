# Локальная CRM-система и Калькулятор 3D-печати

Это локальное веб-приложение для управления студией 3D-печати. Оно включает в себя CRM для управления заказами, калькулятор стоимости печати, а также систему управления складом материалов и парком принтеров.

## Основной функционал

1.  **Канбан-доска:** Управление заказами с отслеживанием статусов: "Согласование", "Очередь", "В работе", "Готов".
2.  **Калькулятор стоимости (Ядро):** Рассчитывает стоимость печати, учитывая:
    *   Себестоимость материала.
    *   Затраты на электроэнергию (потребляемая мощность * время печати * тариф).
    *   Амортизацию принтера (стоимость / ресурс * время печати).
    *   Стоимость услуг моделирования в зависимости от сложности (Простая, Механика/Средняя, Сложная/Органика).
3.  **Склад (Материалы):** Управление запасами филамента (FDM) и смолы (SLA). При смене статуса заказа на "Готов", израсходованный материал автоматически списывается со склада.
4.  **Принтеры:** Управление парком принтеров с указанием их мощности, стоимости и ресурса для точного расчета амортизации и электроэнергии.
5.  **Настройки:** Установка базовых параметров, таких как текущий тариф на электроэнергию.

## Как запустить на Windows 11

### Предварительные требования

У вас должен быть установлен **Python** (рекомендуется версия 3.8 или новее). Вы можете скачать его с официального сайта: [python.org](https://www.python.org/downloads/windows/). При установке обязательно поставьте галочку **"Add Python to PATH"**.

### Шаги по установке и запуску

1.  **Скачайте проект.**
    На странице проекта в GitHub нажмите зеленую кнопку **"<> Code"** и выберите **"Download ZIP"**. После скачивания распакуйте этот архив в любую удобную папку на вашем компьютере.

2.  **Откройте командную строку.**
    Откройте распакованную папку проекта. Кликните левой кнопкой мыши в адресную строку папки (наверху), сотрите весь путь, напишите `cmd` и нажмите Enter. У вас откроется черное окно командной строки, которое уже находится в нужной папке.

3.  **Создайте виртуальное окружение (рекомендуется).**
    Виртуальное окружение изолирует зависимости проекта от вашей основной системы.
    ```cmd
    python -m venv venv
    ```

4.  **Активируйте виртуальное окружение.**
    ```cmd
    venv\Scripts\activate
    ```
    *Вы увидите `(venv)` в начале строки вашей командной оболочки.*

5.  **Установите необходимые зависимости.**
    В проекте есть файл `requirements.txt`. Установите библиотеки, выполнив команду:
    ```cmd
    pip install -r requirements.txt
    ```

6.  **Запустите приложение одной командой.**
    После успешной установки зависимостей, запустите сервер Flask:
    ```cmd
    python app.py
    ```

7.  **Откройте приложение в браузере.**
    После запуска в консоли вы увидите сообщение о том, что сервер работает (обычно это `Running on http://127.0.0.1:5000/`).
    Откройте ваш любимый браузер (Chrome, Edge, Firefox) и перейдите по адресу:
    **http://127.0.0.1:5000/** или **http://localhost:5000/**

## Как пользоваться программой

1.  **Первичная настройка:**
    *   Перейдите на вкладку **"Настройки"** и задайте актуальный тариф на электроэнергию (₽/кВт*ч). Нажмите "Сохранить".
    *   Перейдите на вкладку **"Принтеры"** и добавьте ваши 3D-принтеры, указав их мощность (в Ваттах), стоимость и заявленный ресурс в часах.
    *   Перейдите на вкладку **"Склад (Материалы)"** и добавьте катушки/бутылки с материалами, указав тип, общий вес/объем, цену и текущий остаток.

2.  **Расчет стоимости и создание заказа:**
    *   Перейдите на вкладку **"Калькулятор"**.
    *   Выберите нужный материал и принтер из выпадающих списков.
    *   Укажите расчетный вес детали и примерное время печати.
    *   Укажите сложность моделирования (если применимо).
    *   Нажмите **"Рассчитать"**. Система покажет подробную калькуляцию (себестоимость, итоговая цена и разбивка).
    *   Заполните поля "Название заказа" и "Описание" ниже и нажмите **"Сохранить заказ"**, чтобы добавить его в CRM.

3.  **Работа с заказами:**
    *   Перейдите на вкладку **"Канбан-доска"**.
    *   Вы увидите все созданные заказы.
    *   Меняйте статус заказа через выпадающий список (Согласование -> Очередь -> В работе -> Готов).
    *   *Важно:* Когда вы переводите заказ в статус **"Готов"**, система автоматически вычтет вес детали из текущего остатка выбранного материала на складе.

## Резервное копирование

Чтобы сделать бэкап всех клиентов, материалов, заказов и настроек, достаточно просто скопировать файл `database.db` (появляется в папке `instance` после первого запуска) на флешку или в облако. В случае переустановки программы просто поместите этот файл обратно.

## Особенности архитектуры

*   Проект работает локально без необходимости настройки сложного сервера.
*   База данных (`database.db`) создается автоматически при первом запуске в виде обычного файла SQLite.
*   Интерфейс представляет собой Single Page Application (SPA), поэтому переключение между вкладками происходит мгновенно без перезагрузки страницы.
