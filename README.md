# Управление 3D-печатью (ERP/CRM Система)

Полноценная локальная ERP/CRM система, разработанная специально для студий 3D-печати и самозанятых мейкеров. Приложение объединяет в себе продвинутый калькулятор себестоимости (FDM/SLA), ведение клиентской базы, складской учет материалов и автоматическую генерацию бухгалтерских документов.

---

## 🌟 Ключевые возможности

### 🧮 Продвинутый калькулятор и аналитика
*   **Гибкое ценообразование:** Учет стоимости материалов (вес/шт.), амортизации оборудования, тарифов на электроэнергию, а также времени работы оператора и услуг моделирования.
*   **Стратегии продаж:** Наценка в процентах, целевая прибыль или фиксированная цена. Поддержка скидок и учета эквайринга.
*   **What-If Аналитика:** Интерактивный ползунок для симуляции изменения цены и мгновенного расчета итоговой чистой прибыли.

### 📋 Канбан и управление клиентами
*   **Канбан-доска заказов:** Наглядное управление статусами ("Согласование", "Очередь", "В работе", "Готов").
*   **Карточки клиентов:** Ведение базы заказчиков с контактными данными, реквизитами и историей заказов.

### 📦 Складской учет (ТМЦ)
*   **Учет материалов:** Автоматическое списание пластика (филамента) и фотополимерной смолы при переходе заказа в статус "Готов".
*   **Штучные товары:** Учет упаковки, крепежа и других расходных материалов.

### 📄 Документооборот (Локальный ЭДО)
*   **Генерация документов:** Создание готовых к печати документов на основе данных заказа:
    *   Коммерческое предложение (КП)
    *   Договор / Оферта
    *   Расписка
    *   Счет на оплату
    *   Товарная накладная (ТОРГ-12)
    *   Акт выполненных работ
    *   УПД (Универсальный передаточный документ)
*   Все документы адаптированы для печати в формате A4 (`@media print`) и сохранения в PDF.

### ✨ Встроенный AI-Ассистент (Gemini Copilot)
*   Интегрированный чат-бот на базе Google Gemini.
*   Ассистент всегда доступен через плавающую кнопку, знает контекст вашей работы и может помочь с расчетами параметров печати, материалами или общением с клиентами.

## 🛠 Стек технологий

*   **Backend:** Python 3.11, Flask
*   **База данных:** SQLite (SQLAlchemy)
*   **Frontend:** HTML5, CSS3 (Bootstrap 5 CDN), Vanilla JavaScript
*   **ИИ Интеграция:** `google-genai` (Google Gemini API)

## 🚀 Установка и запуск

### Требования
*   Установленный Python 3.10+ (рекомендуется 3.11).

### Шаги установки (Windows / Linux)

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/your-username/3d-print-crm.git
   cd 3d-print-crm
   ```

2. **Создайте и активируйте виртуальное окружение:**
   Создайте venv стандартными средствами Python, затем активируйте его.

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Запустите приложение:**
   ```bash
   python app.py
   ```
   *Приложение автоматически откроет браузер по адресу http://127.0.0.1:5000*

## 📦 Сборка в исполняемый файл (.exe)

Для удобного распространения и использования на Windows без установки Python, систему можно скомпилировать в один `.exe` файл с помощью PyInstaller.

**Важно:** Не используйте флаг `--noconsole`. Консольное окно необходимо для того, чтобы сервер можно было корректно завершить (закрыв крестиком окно консоли).

**Команда для сборки:**
```cmd
pyinstaller --onefile --add-data "templates;templates" app.py
```

Скомпилированный файл появится в папке `dist`. При первом запуске он автоматически создаст рядом с собой базу данных `database.db` и папку `uploads`.

## 🤖 Интеграция с ИИ (Настройка Gemini)

Для работы встроенного AI-ассистента требуется API-ключ от Google Gemini.

1. Перейдите в [Google AI Studio](https://aistudio.google.com/app/apikey).
2. Авторизуйтесь с помощью Google-аккаунта.
3. Нажмите **"Create API key"** и скопируйте полученный ключ.
4. В приложении (CRM) перейдите на вкладку **"Настройки"**.
5. Вставьте ключ в поле **Gemini API Key** и нажмите **Сохранить**.
6. Теперь вы можете нажать на плавающую кнопку со звездочками (✨) в правом нижнем углу и общаться с ассистентом!

---

### Обновление базы данных (При ошибках)
Если вы обновляете приложение с предыдущих версий и получаете ошибку `OperationalError: no such column: settings.gemini_api_key`, просто удалите файл `database.db` в корне проекта (или рядом с `.exe`). При следующем запуске программа автоматически создаст новую базу данных с актуальной структурой.
